# 🤖 AgilBot — Identificador de Conceitos Ágeis

Chatbot interativo em página única (`HTML/CSS/JS`) para identificar e explicar conceitos de desenvolvimento ágil e Scrum a partir de perguntas diretas ou descrições de situações do dia a dia[cite: 9].

## ✨ Funcionalidades

- **Reconhecimento instantâneo:** Funciona 100% no navegador, sem necessidade de servidor ou instalação.
- **Respostas estruturadas:** Exibe definição objetiva, categoria, papel responsável e exemplo prático.
- **Base completa:** Cobre Valores, Pilares, Papéis, Fases, Artefatos, Cerimônias e Práticas da Metodologia Ágil do MEC (v1.1)[cite: 2, 11, 13, 41].
- **Recursos extras:** Filtro por categoria, integração opcional com a API Gemini e exportação do histórico em `.md`.

## 🚀 Como Usar

1. Baixe o arquivo `agilbot.html`.
2. Dê um duplo clique para abri-lo em qualquer navegador moderno (Chrome, Edge, Firefox ou Safari).
